# GitHub publishing notes

## Before committing

1. Replace all real Wi-Fi SSIDs and passwords with placeholders.
2. Search the repository for:
   - `WIFI_PASSWORD`
   - `ROUTER_PASSWORD`
   - your real SSID
3. Do not commit secrets.

## Suggested first commit

`docs: document ESP8266 weather API integration`

## Suggested repository description

ESP8266 NodeMCU IoT project integrating AP+STA networking, a web dashboard, PWM heartbeat LED control, Open-Meteo weather API access, HTTPS, and ArduinoJson parsing.
